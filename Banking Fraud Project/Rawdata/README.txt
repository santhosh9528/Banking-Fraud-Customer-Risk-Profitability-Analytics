The data is synthetic and designed for an end-to-end data analyst portfolio project.

Intentional data-quality issues are included:
- Duplicate records
- Missing IDs / values
- Invalid customer, account, branch, and loan references
- Inconsistent text / currencies / status values
- Invalid dates
- Negative numeric values
- Outliers

Fraud-style patterns are intentionally planted:
- Multiple transactions in a short period
- Unusually high transaction amounts
- Sudden location changes
- Multiple device usage
- Repeated failed transactions
- High-value transactions after unusual activity

Loan/default behavior is approximately linked with credit score and repayment behavior so the
statistical analysis can reveal realistic relationships.

Do not blindly remove all suspicious records. Document cleaning rules and preserve legitimate
outliers where appropriate.
